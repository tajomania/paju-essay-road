# 파주, 텍스트로 걷고 나의 길을 사유하다

공통 읽기 자료를 자신의 진로로 해석하고, 학생이 직접 에세이를 작성한 뒤 AI 피드백을 비판적으로 검토하는 4단계 수업 웹앱입니다. 학생은 휴대폰·태블릿으로, 교사는 컴퓨터로 이용합니다.

## 이용 흐름

1. 교사가 웹앱에 가입하고 수업을 생성합니다. 가입 시 복구 코드를 보관합니다.
2. 파주 소재의 자체 작성 탐구 글을 선택하거나 키워드로 AI 자료를 생성합니다. 기존 글을 직접 등록할 수도 있습니다. 책 검색은 Open Library의 실제 서지 결과를 사용합니다.
3. 교사가 자료를 검토한 뒤 공통 자료로 확정하고 학생 참여 링크를 공유합니다.
4. 학생이 수업용 별명과 비밀번호로 참여합니다. 같은 정보로 다른 기기에서도 다시 접속할 수 있습니다.
5. 읽기 메모·진로 연결 키워드 → 중심 질문·주장·개요 → 직접 작성한 초안·피드백 수용/거절 기록 → 최종 에세이·댓글·성찰로 이어집니다.

학생과 배포를 받는 교사는 별도 설치나 API 키 입력이 필요 없습니다. 운영자가 서버와 AI 연결을 한 번 설정해야 합니다. **GitHub Pages만으로는 서버 저장과 AI 분석을 실행할 수 없습니다.** GitHub는 소스 및 자동 배포를 관리하고 Cloudflare Workers/D1이 앱과 데이터를 실행합니다.

## 포함 기능

- 교사별 계정과 복구 코드, 수업별 참여 코드·링크
- 파주 책·출판, 접경·평화, 환경·지역 변화에 관한 탐구 글 3종
- 교사 키워드 기반 AI 읽기 자료 생성, 직접 자료 편집·확정
- 확인 가능한 서지 데이터 기반 관련 도서 검색
- 학생 관심 분야와 공통 글을 연결한 주제 후보, 학급 주제 보드
- 학생이 직접 작성하는 주장·개요·초안·최종본
- 사진 최대 4장, 순서 조정·압축·문자 인식·학생 확인
- 강점, 우선 수정할 점 3개, 탐구 질문 중심 AI 피드백
- 피드백 분석 당시 초안 보존, 수용 기록과 논리적 거절 사유서
- 학급 내부 최종 글·댓글·소감 게시, 교사 숨김 관리
- 자동 저장, 학생 진행 현황, 학생별 기록 조회
- 교사의 학생 비밀번호 초기화, 수업 종료·재개·삭제, JSON 기록 내려받기

## AI 원칙

에세이 전체, 대체 문장, 문단, 주장, 개요를 대신 생성하는 학생 기능은 제공하지 않습니다. 피드백은 진로 분야 전문가 관점의 논리 검토와 수정 과제로 제한합니다. 실제 전문가 자격을 주장하지 않으며 점수를 매기지 않습니다. AI의 제안에 동의하지 않을 경우 학생이 자신의 근거와 진로 가치관을 설명합니다. 프롬프트만으로 모든 모델 출력을 완전히 보장할 수는 없으므로 교사가 결과를 함께 검토합니다.

AI가 연결되지 않은 상태는 화면에 명시하고 가짜 AI 응답을 제공하지 않습니다. 자료 직접 등록, 학생 글쓰기, 학급 공유는 계속 사용할 수 있습니다. 실제 AI·사진 인식 검증에는 운영자 API 키가 필요합니다.

## 배포

[GitHub·Cloudflare 배포 안내](docs/DEPLOY.md)를 따릅니다. `.github/workflows/deploy.yml`은 운영자가 `DEPLOY_ENABLED=true`를 설정한 뒤 main 브랜치의 변경을 자동 배포합니다. 초기 설정이 없는 상태에서는 배포를 건너뜁니다. CI는 항상 문법·권한·데이터 흐름 테스트와 배포 패키지를 검사합니다.

## 로컬 실행

Node.js 24 이상과 pnpm 11.25.0을 사용합니다.

```sh
pnpm install
pnpm db:local
pnpm dev
```

`http://localhost:8787`에서 이용합니다. AI를 시험하려면 `.dev.vars.example`을 `.dev.vars`로 복사하고 운영자 키를 입력합니다. `.dev.vars`는 Git에 포함하지 않습니다. 운영용 데이터와 로컬 데이터는 별개입니다.

```sh
pnpm check
pnpm test
pnpm exec wrangler deploy --dry-run
```

테스트는 실제 SQLite 스키마를 사용해 학급 간 접근 차단, 초안 비공개, 게시·댓글, 숨김 관리, 세션 초기화, 수업 삭제, AI 요청 형식과 초안 스냅샷을 검증합니다. 테스트의 AI 응답은 모의 응답이며 실제 모델 품질을 보증하지 않습니다.

## 데이터와 운영

비밀번호는 PBKDF2로 해시하고, 로그인 세션은 HttpOnly·SameSite 쿠키를 사용합니다. 운영 HTTPS에서 Secure를 적용합니다. 학생 초안과 수정 기록은 해당 학생과 담당 교사만 조회하며, 공유한 주제·게시글은 해당 학급 내부에만 공개합니다. 사진은 인식 요청 시 API로 전송하되 앱 서버에 원본을 보관하지 않습니다. 문자 인식 결과와 글쓰기 기록은 D1에 저장합니다.

AI는 운영자의 OpenAI API 키를 서버에서 사용합니다. 기본 요청 상한은 학생 12회/일, 교사 30회/일, 학급 150회/일, 앱 전체 1,000회/일입니다. 하루는 한국 시간 기준입니다. 실패한 AI 요청도 요청 상한에 포함될 수 있습니다. 이 상한은 비용의 정확한 금액 상한이 아니므로 제공사 결제·사용량 설정도 운영자가 관리해야 합니다. `AI_DAILY_LIMIT`, `CLASS_AI_DAILY_LIMIT`, `OPENAI_MODEL`을 환경변수로 조정할 수 있습니다.

수업 생성은 교사당 하루 10개, 학급은 최대 300명입니다. 수업 코드와 비밀번호를 공개 게시판에 올리지 마세요. 가입을 제한하려면 `TEACHER_INVITE_CODE`를 서버 비밀값으로 설정합니다. 학생은 실명 대신 별명을 사용하고 사진 속 개인정보를 가립니다. 학기 종료 후 교사는 필요한 기록을 내려받고 수업을 삭제할 수 있습니다. 별도의 운영자 관리자 화면, 이메일 전송·복구, 기관 SSO, 학부모 공개 게시판, 자동 보관기간 삭제 기능은 포함하지 않았습니다.

첨부 수업안의 1차시 탐색·질문, 2차시 직접 초고·비판적 수정·공유 흐름을 네 화면으로 구성했습니다. 수업안의 외부 서비스 설명을 사실 보증으로 사용하지 않았으며, AI 결과는 오류가 있을 수 있습니다.
