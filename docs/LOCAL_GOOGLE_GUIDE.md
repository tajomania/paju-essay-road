# 교사 PC 설치 · 학교 Google 계정 연결 안내

## 준비

Windows 10/11 64비트 교사 PC와 인터넷, 학생이 접속할 같은 학교망을 준비합니다. 설치 파일에는 Node.js 실행 환경이 포함되어 별도 개발 도구나 관리자 설치가 필요 없습니다. 학교 보안 정책이 프로그램 실행 또는 교실 PC 접속을 제한하면 담당자에게 허용 여부를 확인합니다.

## 1. 설치와 실행

1. GitHub Releases의 **Paju-Essay-Road-Windows.zip**을 내려받습니다.
2. 압축 파일 안에서 실행하지 말고 교사 PC의 폴더에 전체 압축을 풉니다.
3. **Start-Classroom.cmd**를 실행합니다. 교사 화면이 http://localhost:8788 에 열립니다.
4. 교사 계정을 가입하고 복구 코드를 보관합니다. 로컬 버전 계정은 공개 웹앱 계정과 별개입니다.
5. 수업이 끝나면 **Stop-Classroom.cmd**를 실행합니다. 다음 수업 때 다시 실행하면 이전 기록을 이어서 사용합니다.

## 2. goedu.kr 학교 Google 계정으로 AI 준비

1. 교사 브라우저에서 https://aistudio.google.com/api-keys 를 엽니다.
2. 자신의 **학교 Google 계정(@goedu.kr)**으로 로그인했는지 확인합니다.
3. 계정의 프로젝트에서 Gemini API 키를 생성합니다. 현재 AI Studio에서 새로 발급하는 키를 사용합니다.
4. 앱의 **내 AI 연결 → goedu.kr 학교 Google API 등록**를 선택합니다.
5. 학교 이메일(@goedu.kr), API 키와 모델 이름을 입력합니다. 기본 모델은 `gemini-3.1-flash-lite`입니다. 계정에서 허용한 모델로 변경할 수 있습니다.
6. 전송 자료와 이용량 안내를 확인하고 설정을 저장합니다.
7. **저장된 연결 테스트**로 실제 연결 성공을 확인합니다.

일반 Gemini 웹 서비스에 로그인한 것만으로 이 앱의 API 사용 권한이 생기지는 않습니다. 이 버전은 학교 Google 계정에서 발급한 API 키로 연결하며, Google OAuth 로그인 기능을 제공하는 것은 아닙니다. 학교 계정의 소유나 도메인을 앱이 자체 인증하지 않습니다.

Google Workspace 관리자는 AI Studio 사용을 제한할 수 있고, 프로젝트 권한에 따라 키를 발급하지 못할 수 있습니다. 해당 경우 학교 계정 관리자에게 AI Studio, Google Cloud 프로젝트 및 Gemini API 키 생성 권한을 확인합니다. 학생이 각자 AI Studio에 가입할 필요는 없습니다. [Google 공식 학교 계정 안내](https://ai.google.dev/gemini-api/docs/workspace), [API 키 안내](https://ai.google.dev/gemini-api/docs/api-key).

## 3. 학생 참여

1. 교사 PC와 학생 휴대폰·태블릿을 서로 접속 가능한 같은 학교망에 연결합니다.
2. 교사 홈 화면의 **학생 접속 주소**를 확인합니다. `localhost`는 학생에게 공유하지 않습니다.
3. 수업을 생성하고 공통 자료를 확정한 뒤 **학생 참여 링크 복사**로 학교망 주소가 포함된 링크를 공유합니다.
4. 학생은 링크와 수업용 별명·비밀번호로 참여합니다. Google 로그인이나 API 키를 요구하지 않습니다.
5. 수업 중 교사 PC와 앱을 켜 두고 절전 모드를 방지합니다.

접속이 안 되면 교사 PC IP 주소, 같은 망 여부, Wi-Fi 단말 간 격리, Windows/학교 방화벽의 TCP 8788 허용 여부를 담당자와 확인합니다. 앱이 방화벽이나 보안 정책을 자동 변경하지 않습니다. 여러 네트워크가 있으면 학생과 같은 망의 주소를 공유하세요. 다른 학교나 교실 밖에서 이 로컬 주소로 접속하는 기능은 제공하지 않습니다.

기본 학교망 연결은 HTTP입니다. 수업망의 통신 보호가 필요하면 학교 관리자가 인증서로 HTTPS를 구성합니다. `LOCAL_TLS_CERT`, `LOCAL_TLS_KEY`, 필요 시 `LOCAL_ALLOWED_HOSTS`를 지정해 HTTPS 서버를 실행할 수 있습니다. 학교 외부 인터넷에 단순 포트 개방으로 노출하지 않습니다.

## 4. 데이터와 키

수업 데이터는 교사 PC의 `%LOCALAPPDATA%\PajuEssayRoad`에 저장합니다. API 키는 로컬 데이터베이스에 암호화해 저장하고, 키 설정 변경은 교사 PC의 localhost 접속에서만 허용합니다. 학생이나 다른 교사는 키 원문을 조회할 수 없습니다.

AI 분석할 때 공통 읽기 자료·희망 분야·에세이 초안·사진이 **Google Gemini API**로 전송됩니다. 로컬 설치가 AI 분석까지 오프라인이라는 뜻은 아닙니다. 키와 수업 기록을 개발자의 공개 Cloudflare 앱으로 보내지 않습니다. 사진 원본은 앱 서버에 저장하지 않습니다. 개인 계정의 API 이용량과 결제 정책이 적용됩니다.

AI는 완성 에세이·대체 문장을 작성하는 기능으로 제공하지 않습니다. 학생이 직접 초안을 쓰고, 사진 글자 인식을 확인하고, 피드백의 수용·거절 사유를 작성합니다. 모델 응답과 손글씨 인식에는 오류가 있을 수 있습니다.

수업 기록은 앱에서 내려받을 수 있습니다. PC 전체 데이터를 백업하려면 앱을 종료한 뒤 데이터 폴더 전체를 복사합니다. `encryption.key`도 함께 보관하고 폴더를 학생에게 공유하지 않습니다. 이 키 파일을 분실하면 저장된 AI 키를 다시 연결해야 합니다. 업데이트는 앱을 종료하고 실행 파일 폴더를 교체하면 됩니다. 데이터 폴더는 별도로 유지됩니다.

## 문제 해결

- Google 권한 오류: 학교 계정의 AI Studio 및 프로젝트 API 권한, 키 상태 확인
- 모델 오류: 해당 계정에서 사용할 수 있는 모델 이름 확인
- 한도 오류: 앱의 하루 요청 한도 및 Google API 사용량 확인
- 실행 오류: `%LOCALAPPDATA%\PajuEssayRoad\server-error.log` 확인, 다른 프로그램의 8788 포트 사용 확인
- 보안 정책 차단: 학교 담당자의 실행 허용 절차 이용

실제 학교 계정 연결 성공 여부는 해당 교사의 API 키로 연결 테스트를 수행해야 확인할 수 있습니다.

## 자료 전송 동의 오류 해결

‘자료 전송 동의의 [필수] 체크박스를 선택’ 또는 ‘선택한 외부 AI로 전송되는 자료 안내를 확인’이라는 문구는 Google 연결 오류가 아니라 설정 저장 전에 동의가 빠진 상태입니다. 내 AI 연결에서 전송되는 자료 안내를 읽고 [필수] 체크박스를 직접 선택한 뒤 설정 저장을 누릅니다. ‘API 키가 저장되었습니다’ 안내 후 저장된 연결 테스트를 실행하세요. 체크되지 않은 상태에서는 API 키를 저장하지 않습니다. 새 키를 입력했을 때도 저장을 먼저 완료하세요.

## Google API 일시 오류

Google HTTP 503 · TEMPORARY_UNAVAILABLE은 Google 서비스의 일시 오류입니다. 앱은 최대 2회 자동 재시도합니다. 계속 실패하면 잠시 후 다시 테스트하세요. 이 오류만으로 API 키를 다시 발급할 필요는 없습니다. KEY_INVALID는 키 확인, PERMISSION은 프로젝트 권한, BILLING은 결제·무료 이용 조건, QUOTA는 한도 확인이 필요합니다. 계정 설정 오류는 자동 재시도하지 않습니다.

## 모델별 응답 지연 해결

기존 gemini-3.5-flash-lite에서 503·응답 지연이 반복되고 다른 모델이 응답하는 사례를 확인했습니다. 내 AI 연결의 모델을 gemini-3.1-flash-lite로 변경하고 전송 동의 확인 → 설정 저장 → 연결 테스트를 실행하세요. API 키를 새로 발급할 필요는 없습니다. 모델별 서비스 상태와 계정 한도에 따라 결과는 달라질 수 있습니다. 앱이 다른 제공사나 다른 모델로 자동 전환하지 않습니다.

## 학생 활동 기록 Excel 다운로드

수업 관리의 **활동 기록 Excel 다운로드**를 누르면 `.xlsx` 파일이 저장됩니다. Excel에서 바로 확인·편집할 수 있습니다. 학생 현황, 활동 상세, AI 피드백, 게시글, 댓글, 공통 자료를 시트별로 확인하세요. 교사 메모 열은 자유롭게 작성할 수 있습니다. 긴 글은 셀 선택 후 수식 입력줄에서 확인하거나 행 높이를 늘리세요. 다운로드 파일 편집은 웹앱 기록에 자동 반영되지 않습니다.
