TEACHER GUIDE

내 수업에 AI 연결하기

학교 Google 계정(Gemini)으로 교사 PC에서 사용하려면 Windows 설치·Google 연결 안내를 확인하세요.

교사 한 번의 설정으로 자신의 모든 수업에 AI를 연결합니다. 학생은 앱 주소와 참여 코드만 사용하며 API 키를 입력하지 않습니다.

1. 이용 방식 선택

교사로 로그인한 후 수업 목록 또는 수업 관리 화면의 내 AI 연결을 누릅니다.

  • 공용 Cloudflare AI: 별도 키 없이 시작합니다. 운영자의 공용 이용량 한도 내에서 사용할 수 있습니다.
  • 내 Cloudflare 계정: 자신의 Account ID와 Workers AI API 토큰으로 연결합니다. 해당 교사의 수업 요청은 교사 계정의 이용량에 포함됩니다.
  • AI 사용 끄기: 직접 읽기·글쓰기·게시와 댓글은 계속 사용할 수 있습니다.

2. 개인 계정 준비

  1. Cloudflare에 가입하고 이메일을 인증합니다.
  2. 대시보드에서 Workers AI → Use REST API를 엽니다.
  3. Create a Workers AI API Token을 선택하고 해당 계정에 적용되는 토큰을 생성합니다. 이 토큰을 복사합니다.
  4. 같은 화면의 Get Account ID에서 Account ID를 복사합니다.

직접 권한을 지정하는 경우 Workers AI - Read와 Workers AI - Edit가 필요합니다. 가능한 자신의 해당 계정으로 범위를 제한하세요. 공식 연결 안내 ↗

3. 앱에 저장하고 확인

  1. 내 AI 연결 → 내 Cloudflare 계정으로 연결을 선택합니다.
  2. Account ID와 API 토큰을 입력합니다.
  3. 내 계정의 하루 요청 한도를 정하고 자료 전송 안내를 확인합니다.
  4. 설정 저장 후 저장된 연결 테스트를 누릅니다. 테스트는 학생 글 없이 짧은 연결 확인 문장만 전송합니다.
  5. 성공 메시지를 확인한 후 학생 참여 링크를 공유합니다.

토큰은 서버에서 AES-GCM으로 암호화해 저장합니다. 토큰 원문은 학생, 다른 교사, 설정 조회 응답에 노출하지 않습니다. 계정을 바꿀 때는 새 토큰을 함께 입력합니다. 같은 계정의 설정만 수정할 때는 토큰 칸을 비워 기존 토큰을 유지할 수 있습니다.

4. 수업에서 활용

  • 1단계: 교사 키워드로 읽기 자료를 만들고 교사가 검토·확정합니다.
  • 2단계: 공통 글과 관심 분야를 연결한 주제 후보를 참고합니다. 주장과 개요는 학생이 씁니다.
  • 3단계: 학생이 직접 쓴 초안 사진을 등록합니다. 인식된 글자를 학생이 확인한 뒤 피드백을 요청합니다.
  • 피드백: 강점·우선 수정할 점·생각을 확장할 질문을 제공합니다. 완성 글이나 대체 문장을 제공하지 않도록 설정합니다. 학생이 수용 또는 거절 사유를 작성합니다.

읽기 자료, 희망 분야, 초안과 사진은 분석할 때 Cloudflare Workers AI로 전송됩니다. 사진 원본은 앱 서버에 저장하지 않습니다. 학급의 데이터 처리 안내에 이 전송 범위를 포함하세요. AI 판단과 문자 인식에는 오류가 있을 수 있으므로 학생과 교사가 함께 확인합니다.

5. 연결 문제와 이용량

  • 인증·권한 오류: Account ID와 토큰이 같은 계정인지, Workers AI 권한이 있는지 확인합니다.
  • 이용 한도: 앱의 요청 한도 또는 Cloudflare 계정의 AI 한도에 도달하면 분석이 중단됩니다. 개인 연결 오류 시 공용 계정으로 자동 전환하지 않습니다.
  • 사진 인식: 선명한 사진을 한 장씩 먼저 시험하세요. 읽기 어려운 부분은 직접 수정합니다.
  • 연결 해제: 개인 연결 삭제 또는 공용 방식으로 변경하면 저장된 개인 토큰이 삭제됩니다. 유출이 의심되면 Cloudflare에서도 토큰을 폐기하고 새로 발급하세요.

하루 요청 한도는 금액 한도가 아닙니다. 실패한 요청과 연결 테스트도 제공사의 이용량에 포함될 수 있습니다. 비용과 제공사 한도는 Cloudflare 공식 요금 안내에서 확인하세요.
