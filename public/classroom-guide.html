주소 하나, 수업 코드로 함께하는 웹 수업

공통 접속 주소: https://paju-essay-road.essay-road.workers.dev/

교사와 학생 모두 같은 주소로 접속합니다. Windows 설치와 같은 학교망 연결이 필요하지 않습니다.

교사: 웹에서 수업 방 만들기

  1. 첫 화면에서 교사 작업실을 열고 교사 가입 또는 로그인을 합니다. 복구 코드를 보관하세요.
  2. 새 수업 만들기를 눌러 수업 이름을 입력합니다.
  3. 수업에 자동 발급된 8자리 참여 코드를 학생에게 알려 주세요. 수업 코드 복사나 학생 참여 링크 복사를 이용할 수 있습니다.
  4. 공통 읽기 자료를 준비해 확정하고 학생 진행 현황과 게시판을 관리합니다.
  5. 활동 기록 Excel 다운로드로 학생 기록을 확인·편집할 수 있습니다.

학생: 코드로 참여하기

  1. 휴대폰·태블릿·컴퓨터에서 공통 웹주소를 엽니다.
  2. 첫 화면에 선생님이 알려 준 수업 코드를 입력합니다.
  3. 처음 참여할 때는 수업용 별명과 비밀번호를 정합니다. 다시 참여할 때는 다시 참여하기 탭에서 같은 코드·별명·비밀번호를 입력하세요.
  4. 함께 읽기 → 진로와 주제 → 직접 작성한 초안과 피드백 → 완성 글·댓글·소감의 네 단계를 진행합니다.

AI와 수업 기록

교사가 내 AI 연결에서 학교 Google Gemini API 키를 한 번 등록하면 해당 교사의 학생들이 AI를 함께 이용합니다. 학생에게 API 키를 요구하지 않습니다. 교사용 AI 연결 안내

웹 수업 기록은 서버에 저장되어 다른 기기에서도 이어갈 수 있습니다. 교사 PC를 계속 켜 둘 필요가 없습니다. 기존 PC 설치 버전의 계정·수업·API 키는 웹에 자동 이전되지 않으므로 웹에서 교사 계정과 수업 방을 새로 만드세요.
