LOCAL CLASSROOM

내 컴퓨터에서 시작하는 수업

교사 PC에 수업 기록을 저장하고, 같은 학교망의 학생들과 네 단계 에세이 수업을 진행합니다.

Windows 로컬 실행 패키지 다운로드전체 설치 안내문 ↗

1. 내려받고 실행

  1. Windows 10/11 64비트 PC에서 ZIP 전체 압축을 풉니다.
  2. Start-Classroom.cmd를 실행하면 교사 화면이 열립니다. Node.js 실행 환경이 포함되어 있습니다.
  3. 교사 계정을 가입하고 수업을 만듭니다. 공개 웹앱과 로컬 버전의 계정·기록은 별개입니다.
  4. 수업을 마치면 Stop-Classroom.cmd를 실행합니다.

2. 학교 Google 계정으로 Gemini 연결

  1. Google AI Studio에서 자신의 @goedu.kr 학교 계정으로 로그인합니다.
  2. 해당 계정의 프로젝트에서 Gemini API 키를 발급합니다.
  3. 앱의 내 AI 연결 → goedu.kr 학교 Google API 등록를 선택합니다.
  4. 학교 이메일(@goedu.kr), 키와 모델 이름을 저장한 뒤 저장된 연결 테스트로 확인합니다.

학교 Google 계정 로그인을 앱이 직접 대행하는 방식은 아닙니다. 학교 계정에서 발급한 API 키로 Gemini API를 연결합니다. 일반 Gemini 웹 로그인과 API 권한은 별개이며, 학교 관리자가 AI Studio 또는 프로젝트 키 발급을 제한할 수 있습니다. Google 공식 계정 안내 ↗

3. 학생에게 링크 공유

  1. 교사 PC와 학생 기기를 서로 접속 가능한 같은 학교망에 연결합니다.
  2. 교사 홈 화면의 학생 접속 주소를 확인합니다.
  3. 수업의 학생 참여 링크 복사로 링크를 공유합니다. 학생에게 localhost 주소를 공유하지 않습니다.
  4. 학생은 별명·비밀번호로 참여합니다. 학생용 Google 계정이나 API 키는 필요 없습니다.

수업 중 교사 PC와 앱을 켜 둡니다. 접속이 안 되면 IP, 방화벽의 TCP 8788, Wi-Fi 기기 격리 여부를 학교 담당자와 확인하세요. 여러 망이 연결돼 있으면 학생과 같은 망의 주소를 선택합니다. 기본 HTTP 연결에 통신 보호가 필요하면 학교 관리자가 HTTPS 인증서를 구성합니다.

4. 저장과 AI 활용

수업 기록은 교사 PC의 %LOCALAPPDATA%\PajuEssayRoad에 저장합니다. 키는 로컬에서 암호화하며, 설정 변경은 교사 PC의 localhost 화면에서만 허용합니다.

AI 분석할 때 자료·희망 분야·초안·사진은 Google Gemini API로 전송됩니다. 로컬 설치도 AI 분석에는 인터넷이 필요합니다. API 이용량과 비용은 교사 계정에 적용됩니다. 학생은 직접 쓰고, AI의 피드백을 판단하며 수정합니다.

앱을 종료한 뒤 데이터 폴더 전체를 백업하세요. 암호화 키 파일도 함께 보관하고 학생에게 공유하지 않습니다.
